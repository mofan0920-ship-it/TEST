## 已采用的确定信息

- 生产环境位于阿里云深圳地域。
- 8 个 K8s 节点：`10.78.65.11~14`、`10.78.68.11~14`。
- 本地 FAST 研发管理平台连接云上 K8s 集群完成部署。
- 已采购阿里云负载均衡、WAF、DDoS 攻击防护、域名管理及 OSS。
- 微服务与技术组件清单来自《普惠系统应用架构.pdf》。

## 配置管理范围

- VPC CIDR、可用区、安全组、NACL、路由与 FAST 连接方式。
- K8s 控制面角色、Ingress 类型、SLB 产品类型（CLB/ALB）。
- MySQL、MongoDB、Redis、RabbitMQ、ElasticSearch、FastDFS 的实例地址、部署边界和高可用形态。
- 数据加密、日志留存、备份、容灾与等保级别的实际配置。

## 存储部署说明

- K8s 有状态服务通过 PVC 申请持久卷。
- PV 后端由阿里云上的独立 NFS 存储节点提供。
- OSS 用于合同、影像、附件及导出文件等对象数据。
- 数据库备份、配置备份及归档数据落地集团自建机房，不存放于阿里云。
